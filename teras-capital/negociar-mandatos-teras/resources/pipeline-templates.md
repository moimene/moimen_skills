# Templates por Fase del Pipeline — TERAS Capital

Templates listos para usar en cada fase del pipeline comercial. Rellena los campos entre `{llaves}`.

---

## Fase 1 — Email de Intro

```
Asunto: Operating execution + alignment para {asset/tema}

Estimado/a {nombre},

{Referencia breve: contacto común, evento, o tesis del sponsor que hemos identificado}.

TERAS Capital es un operating manager y coinversor minoritario que se integra con el sponsor para ejecutar creación de valor:

• Ejecución: gestión hands-on, disciplina de caja, KPIs y reporting desde el día 1
• Alineación: fees vinculados a responsabilidad + upside material por performance (sweet equity)
• Reputación: estándar IC-grade, governance y control de execution risk

{1 línea específica sobre por qué {asset/sector} nos encaja y qué execution gap vemos potencial}.

¿Tendría sentido coordinar 20 minutos esta semana para explorar encaje de mandato y economics?

Un saludo,
{firma TERAS}
```

**Variante Follow-up (si no responde)**:
```
Asunto: RE: Operating execution + alignment para {asset/tema}

Estimado/a {nombre},

Permítame insistir brevemente. Creemos que hay un encaje claro entre {necesidad del sponsor} y nuestro modelo de ejecución operativa con alineación económica.

Si {trigger event: cierre próximo / ramp-up / IC pendiente}, estaríamos disponibles para una conversación de 20 minutos.

Un saludo,
{firma}
```

## Fase 4 — IC Pack (estructura de archivos)

Los materiales IC deben prepararse como pack independiente. Ver skill `preparar-ic-teras` para templates detallados.

Componentes mínimos:
1. IC Note (1-3 páginas)
2. KPI Pack (tabla + definiciones)
3. Governance Chart (RACI + comités)
4. Risk Register (top 10)
5. Incentive Alignment Note (1 página)

## Fase 5 — Onboarding Checklist

```markdown
# Post-Deal Onboarding — {Activo}

## Semana 1 ✅
- [ ] Baseline financiero recogido (P&L, balance, cash flow)
- [ ] KPIs definidos y datos baseline capturados
- [ ] Calendario de comités fijado (operating committee + board)
- [ ] Reporting pack template distribuido
- [ ] Reunión de kick-off con management

## Semanas 2–4 ✅
- [ ] Quick wins de cash/control identificados y en ejecución
- [ ] Primer reporting pack completado
- [ ] Pipeline comercial mapeado
- [ ] Riesgos operativos top 5 documentados

## Día 30 ✅
- [ ] Primer "Board/IC-style update" preparado y enviado
- [ ] KPIs con 1 mes de data tracking
- [ ] Feedback del sponsor recogido

## Día 60 ✅
- [ ] Plan comercial detallado presentado
- [ ] Budget/forecast actualizado
- [ ] Governance normalizada (2 comités ejecutados)

## Día 90 ✅
- [ ] Reporting cadence normalizada
- [ ] Todos los KPIs con 3 meses de tracking
- [ ] Assessment formal de performance TERAS
- [ ] Decisión sobre escalado de mandato (si aplica)
```
