## 2. ISHA cap structure (acuerdos estatutarios + side letters)

### Pacto entre socios — clase única Ordinarias

A diferencia de TCH1/Olin (Class A + Class B) o TCH4/Templus (Class A + B + C + D + privilegiadas), TCIH tiene una **única clase Ordinarias** para sus 6 socios. No hay clases reforzadas con derechos económicos diferenciados.

### Side letters

Existen side letters individuales socio-a-socio para regular:
- Mecanismo de cesión crédito intercompany (futuro: cesión 4,08M€ TCIH → socios TCH1 prorrata).
- Posición individual respecto a la subrogación Asterion clase B (debt-rank).
- Reconciliación cuentas corrientes históricas (saldos 55100xx grupo socios).

### Voto

- Voto proporcional al cap% (sin clases de voto reforzado).
- Pool MdL 51,66% → quorum directo mayoría simple.
- Decisiones requieren supermayoría para: acordeón / reducciones capital, fusiones, escisiones, transformación, modificación estatutos, autorización litigios materiales.
