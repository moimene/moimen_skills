# Biblioteca de Correcciones Automáticas — TERAS Capital

Cada ejemplo incluye el texto incorrecto, el texto corregido y la regla violada con explicación.

---

## 1. Posicionamiento / Identidad

### Ejemplo 1.1 — Presentación genérica
| | |
|---|---|
| ❌ MAL | "TERAS es un VC especializado en infra digital y telecomunicaciones." |
| ✅ BIEN | "TERAS es un operating manager y coinversor minoritario que se integra con el sponsor para ejecutar creación de valor industrial y comercial en infra/telco, con alineación por fees y sweet equity." |
| 🔧 Regla | Anti-pattern #1.1 — No llamar a TERAS "VC" |

### Ejemplo 1.2 — Bio para evento
| | |
|---|---|
| ❌ MAL | "TERAS Capital, fondo de capital privado centrado en infraestructura digital." |
| ✅ BIEN | "TERAS Capital: operating manager y coinversor minoritario en proyectos de infraestructura digital, telco, energía y real estate, integrado con sponsors institucionales." |
| 🔧 Regla | Anti-pattern #1.1 — No llamar a TERAS "fondo" |

### Ejemplo 1.3 — Email de intro
| | |
|---|---|
| ❌ MAL | "Como GP de varios vehículos de infra, TERAS ofrece…" |
| ✅ BIEN | "Como operating partner integrado con sponsors de infra, TERAS aporta…" |
| 🔧 Regla | Anti-pattern #1.1 — Solo co-GP con mandato explícito |

### Ejemplo 1.4 — Descripción de servicios
| | |
|---|---|
| ❌ MAL | "Ofrecemos consultoría especializada en creación de valor." |
| ✅ BIEN | "Ejecutamos mandatos operativos de creación de valor con accountability, governance y alineación económica." |
| 🔧 Regla | Anti-pattern #1.2 — No describir como consultoría |

## 2. Economics / Modelo de Negocio

### Ejemplo 2.1 — Propuesta de fees
| | |
|---|---|
| ❌ MAL | "Cobramos un fee y además pedimos equity." |
| ✅ BIEN | "Estructuramos fees según responsabilidad (advisory/management) y alineamos upside material vía sweet equity con vesting y performance gates, de modo que TERAS gane de forma relevante solo si el activo crea valor." |
| 🔧 Regla | Anti-pattern #2.1 — Evitar simplificación; encuadrar como mecanismo de alineación |

### Ejemplo 2.2 — Sweet equity
| | |
|---|---|
| ❌ MAL | "Queremos un porcentaje del equity como compensación." |
| ✅ BIEN | "Proponemos sweet equity como mecanismo de alineación por performance: vesting temporal (3-4 años), good/bad leaver, y performance gates que aseguran que el upside se gana solo si se crea valor medible." |
| 🔧 Regla | Economics — Sweet equity no es compensación, es alineación |

### Ejemplo 2.3 — Pricing agresivo
| | |
|---|---|
| ❌ MAL | "Nuestras fees son las más competitivas del mercado." |
| ✅ BIEN | "Estructuramos fees proporcionales a la responsabilidad del mandato. Ofrecemos diferentes paquetes (Lean / Core / Co-GP track) para adaptar economics al scope." |
| 🔧 Regla | Anti-pattern #2.1 — No hacer claims de mercado sin evidencia |

---

## 3. Promesas y Proyecciones

### Ejemplo 3.1 — EBITDA
| | |
|---|---|
| ❌ MAL | "Vamos a duplicar EBITDA en 12 meses." |
| ✅ BIEN | "El plan de 12 meses prioriza disciplina de caja, ramp-up comercial y optimización de capex; los objetivos se fijan con KPIs y gates, y se revisan en comités con reporting institucional." |
| 🔧 Regla | Anti-pattern #2.2 — No hacer promesas absolutas |

### Ejemplo 3.2 — Retornos
| | |
|---|---|
| ❌ MAL | "Garantizamos un IRR del 15% a los inversores." |
| ✅ BIEN | "El caso base contempla supuestos de underwriting con sensibilidad; los retornos dependen de la ejecución del value creation plan y están sujetos a los riesgos del proyecto." |
| 🔧 Regla | Anti-pattern #2.2 — No garantizar retornos |

### Ejemplo 3.3 — Timeline
| | |
|---|---|
| ❌ MAL | "Cerramos la transacción en 60 días." |
| ✅ BIEN | "Timeline estimado: 60 días desde signing, sujeto a condiciones precedentes (aprobaciones regulatorias, consentimientos, clean-up actions)." |
| 🔧 Regla | Anti-pattern #2.2 — No prometer plazos absolutos |

## 4. Tono y Lenguaje

### Ejemplo 4.1 — Email de seguimiento
| | |
|---|---|
| ❌ MAL | "¡Hola! 😊 Qué buena reunión tuvimos ayer. ¡Estamos super emocionados de trabajar juntos!" |
| ✅ BIEN | "Estimado [nombre], agradecemos la reunión de ayer. A continuación compartimos la propuesta de mandato y economics para su revisión." |
| 🔧 Regla | Anti-pattern #4.2 — Tono institucional, sin emojis ni exceso de familiaridad |

### Ejemplo 4.2 — Pitch verbal
| | |
|---|---|
| ❌ MAL | "Somos la solución más disruptiva y revolucionaria del mercado de infra." |
| ✅ BIEN | "Aportamos un modelo diferenciado de ejecución operativa con alineación económica, adaptado a las necesidades de sponsors de infraestructura." |
| 🔧 Regla | Anti-pattern #2.1 — Sin hype |

---

## 5. Confidencialidad

### Ejemplo 5.1 — Referencia a deals
| | |
|---|---|
| ❌ MAL | "Como hicimos en el deal de [Sponsor X] donde conseguimos un múltiplo de 3.2x…" |
| ✅ BIEN | "Nuestra experiencia en mandatos operativos de infra digital incluye ejecutar planes de creación de valor con resultados medibles." (Sin nombres ni cifras salvo autorización explícita) |
| 🔧 Regla | Anti-pattern #4.1 — No compartir información no autorizada |

### Ejemplo 5.2 — Estructura interna
| | |
|---|---|
| ❌ MAL | "Nuestro equipo está formado por [nombres], con carry de…" |
| ✅ BIEN | "El equipo TERAS asignado al mandato tiene experiencia directa en [sector], con dedicación [full-time/part-time] y accountability definida." |
| 🔧 Regla | Anti-pattern #4.1 — Need-to-know; no revelar estructuras internas |

---

## 6. Audiencia

### Ejemplo 6.1 — IC con tono marketing
| | |
|---|---|
| ❌ MAL (para IC) | "TERAS transformará este activo en un líder del mercado con retornos excepcionales." |
| ✅ BIEN (para IC) | "TERAS ejecutará un mandato operativo con: (1) 100-day plan con KPIs definidos, (2) governance institucional con comité de dirección mensual, (3) alineación por sweet equity con vesting y performance gates. Riesgos principales y mitigantes descritos en sección 6." |
| 🔧 Regla | Anti-pattern #5.1 — IC exige riesgos/mitigantes, no storytelling |

### Ejemplo 6.2 — Sponsor con tono LP
| | |
|---|---|
| ❌ MAL (para sponsor) | "Ofrecemos mecanismos de control que reducen la volatilidad del NAV y protegen el downside de los partícipes del vehículo…" |
| ✅ BIEN (para sponsor) | "Propuesta de mandato: (1) scope operativo [detalle], (2) advisory fee X + management fee Y, (3) sweet equity Z con vesting. Next steps: call de 20' para cerrar scope y timeline." |
| 🔧 Regla | Anti-pattern #5.2 — Sponsor quiere mandato, economics y rapidez |
